Carepatron for ChatGPT

Your next new client's paperwork, sorted from a chat.

A clinician asks ChatGPT for an intake form, a consent form or a cancellation policy. This answers with Carepatron's own template, the sections it covers, and the one thing to do with it next.

See it without installing anything → Code on GitHub

An independent prototype, built for Carepatron to take over. Not affiliated with Carepatron or OpenAI.

Why this and not another template library

Carepatron already publishes thousands of free templates. The gap is what happens after you find one. In a sample of 552 trial practices, the ones that got a real client onto the platform in the first two weeks (an intake form sent, a booking taken, an invoice, a video call) paid at about three times the rate of the ones that didn't. The most common first step was sending an intake form.

So every template here ends with a next step, and intake forms say the same thing: open it, add your client's email, send it. The paperwork is done before the first session.

What it can and can't see

It cannot receive client information, because there is no field to put it in. Every input is a fixed choice: profession, document type, country. The schemas reject anything else, and a test sends a client name to prove it.

Nothing is stored. The server keeps no database and no state between requests. Logs record the tool name and the choices picked, nothing more.

Install it in ChatGPT

You need ChatGPT Plus or higher with developer mode on (Settings → Security and login, or Settings → Plugins). Then at chatgpt.com/plugins choose Add → Create MCP App, enter this URL with No authentication:

https://carepatron-chatgpt-plugin.jacksonirby.workers.dev/mcp

Then type @Carepatron in a new chat.

What's inside

  • 18 Carepatron templates: intake forms for four professions, informed consent, telehealth consent, AI note-taking consent, a cancellation policy, and the original SOAP, DAP and BIRP notes, treatment plans, evaluations and worksheets.
  • A next step on every card, so the answer ends in an action rather than a download.
  • An intake pack checklist by profession and country (US, AU, NZ, GB, CA), with wording to adapt, including what each country's regulators say about consent for AI note-taking. General guidance, not legal advice.
